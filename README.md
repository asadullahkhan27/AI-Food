# 🍱 AI FoodRescue

AI FoodRescue is a prototype platform designed to help reduce food waste through food condition analysis and rescue recommendations.

## Features

- Food image upload
- Food type selection
- Food condition assessment
- Food Rescue Score
- Rescue recommendation
- Impact dashboard
- Future AI computer vision integration

## Tech Stack

- Python
- Streamlit
- Pillow

## Current Version

Prototype / Demo Mode

The current version does use a trained AI model.
